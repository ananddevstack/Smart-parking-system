🚗 Smart Parking System
📖 Overview

The Smart Parking System is a Java-based application designed to streamline parking management by automating vehicle entry, exit, and slot allocation. The system applies core object-oriented programming principles to simulate real-world parking operations in an efficient and structured manner.

🎯 Objectives
To develop an efficient parking slot allocation mechanism
To minimize manual intervention in parking management
To demonstrate practical implementation of OOP concepts
To provide a scalable foundation for real-world parking solutions

✨ Key Features
Automated Slot Allocation – Assigns parking slots dynamically
Vehicle Entry & Exit Tracking – Maintains records of parked vehicles
Real-Time Availability Check – Displays available parking spaces
Simple and Maintainable Design – Clean and modular code structure

🛠️ Technology Stack
Component	Technology
Programming	Java (Core Java)
Concepts Used	OOP (Encapsulation, Classes, Objects)
Frontend (Basic)	HTML (Dummy Interface)
